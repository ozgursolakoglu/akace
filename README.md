# AKACE Grup — Demo Web Sitesi

Ankara / Sincan / Saraycık konut ve AVM projelerini tanıtan örnek web sitesi.

## Çalıştırma
```bash
python -m http.server 3000
```
Sonra http://localhost:3000 adresini açın.

## Önemli: Proje görselleri

Bu depoya şimdilik **HTML kaynak kodu yüklendi**. Mimari proje görselleri ayrıca eklenmelidir. Eksik görseller sebebiyle sitedeki fotoğraflar şu an görünmez.

Bu sürümde iletişim formu bilgileri sadece tarayıcının localStorage alanına kaydedilir; **gerçek e-posta gönderimi yapılmaz**. İletişim bilgileri temsili içeriktir. Kamuya açık kullanıma geçmeden önce firma bilgileri ve KVKK süreçleri doğrulanmalıdır.
