# AKACE Grup — Demo Web Sitesi

Sincan Saraycık konut ve ticari alan projeleri için hazırlanmış örnek kurumsal web sitesi.

## Yerelde çalıştırma

```bash
python -m http.server 3000
```

Ardından `http://localhost:3000` adresini açın.

> **Demo:** Telefon numaraları, e-posta adresleri ve form işlevi örnektir. Form gerçek e-posta göndermez. Yayına almadan önce firma bilgileri, KVKK metinleri ve sunucu tarafı form entegrasyonu tamamlanmalıdır.
